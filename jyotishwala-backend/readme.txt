Complete WordPress Backend, REST API (/wp-json/jyotishwala/v1/), MySQL Database Management, and Admin Dashboard ("JyotishWala App Management") for the JyotishWala Android Application.

== Description ==

JyotishWala Backend separates the Admin Panel from the public Android application and moves all app administration, API key storage, content management, Panchang/Kundli settings, user management, and saved Kundli storage into your existing WordPress Dashboard on Hostinger Shared Hosting.

Features:
1. App Dashboard (Total users, active users, saved Kundlis, API usage, health status, recent activity)
2. App Content Management (WordPress Posts/Categories integration + Sankalp, Tyohar, Gallery, Reviews, Pandits)
3. Panchang Management (Default location: Rishikesh, Uttarakhand, Asia/Kolkata, API config & astronomical fallback)
4. Kundli & Jyotish Management (Lahiri Chitra Paksha Ayanamsha, Bhava/Rashi charts, Vimshottari Dasha, Ashtakoot Milan)
5. Rashifal Management (Daily, Weekly, Monthly, Yearly for all 12 Rashi signs)
6. App Users Management (Search, activate/deactivate, privacy controls, mobile token sessions)
7. Saved Kundli Management (User-wise Kundli storage, search, secure deletion)
8. Home Screen Management (Banners/Slides, featured sections, display order, enable/disable toggles)
9. Notification Management (Announcements, history, optional FCM integration)
10. API & Security Management (Server-side API Vault, masked keys, connection testing, rate limiting)
11. App Settings (App name, logo, version, Hindi/English language config, maintenance mode)
12. Backup & Data Management (JSON export/import, activity logs, error logs)

== Installation ==

1. Compress the `jyotishwala-backend` folder into `jyotishwala-backend.zip`.
2. Log in to your WordPress Admin Dashboard at `https://jyotishwala.com/wp-admin`.
3. Go to **Plugins -> Add New -> Upload Plugin** and upload `jyotishwala-backend.zip`.
4. Click **Activate Plugin**.
5. Open **JyotishWala App Management** in the left WordPress Admin sidebar.
